# MiMind

MiMind is an Android-based mental health support application developed as a university project for the Mobile Programming course at Universitas Sumatera Utara.

The application combines AI-based interaction and interactive questionnaires to provide emotional support and help users gain basic insights into their mental health and personality.

## Overview

MiMind was developed as an academic prototype exploring the use of mobile technology and artificial intelligence in the context of mental health support.

The application provides three main features:

- AI ChatBot for emotional support
- Mental health questionnaire
- MBTI personality test

The project was developed using Kotlin and Android Studio, with Firebase and OpenAI API integration.

## Features

### AI ChatBot

A text-based chatbot that allows users to interact with an AI system for emotional support, motivation, and simple suggestions.

The chatbot uses the OpenAI API to generate responses based on user input.

### Mental Health Questionnaire

An interactive questionnaire designed to help users gain an initial understanding of emotional conditions such as stress and anxiety.

The application provides the questionnaire results along with supportive recommendations.

### MBTI Personality Test

An interactive MBTI-based questionnaire that provides users with their personality type and a brief description.

### User Authentication

Login and registration functionality for accessing the application and personalizing the user experience.

Firebase Authentication is used as part of the authentication system.

### Dark Mode

A dark mode interface is available to improve usability in low-light environments.
